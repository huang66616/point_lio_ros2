# 测试结果摘要（历史证据）

## 短包同条件对照

来源：原工作区 `tools/rosbag_completion_ws/results/comparison_20261031_878e54be42544abcb7119b13fd004903/report.md`。测试为优化前和当前工作树组合改动各两次，顺序 pre1、post1、pre2、post2；ROS 2 Humble、i9-12900KS、Release、相同 MID-360 YAML、相同短包、1.0 倍速、RViz 关闭。播放器每次自然 EOF，节点每次收到 3607 条 IMU、180 帧点云；3 帧为 IMU 初始化，1 帧用于初始地图，176 帧常规处理。外部里程计、Path、注册点云各收到 176 条。

| 指标 | 优化前 | 当前版 |
|---|---:|---:|
| 内部 `t5−t0` 均值 | 10.931 ms | 10.397 ms |
| 内部 `t5−t0` P95 | 14.564 ms | 13.932 ms |
| 点云回调→外部注册点云订阅均值 | 16.851 ms | 16.350 ms |

内部 `t0` 位于 IMU 处理前，`t5` 位于地图插入后，不包含订阅回调预处理、同步等待及后续发布。外部指标由同机单调时钟和精确输出时间戳配对，包含订阅者调度，不包含 bag 发布至节点回调。结果仅证明这一组改动在该短包和条件下的小幅收益，不能归因于单一修改或推广到全部数据。

## 长包优化版单次运行

来源：原工作区 `tools/rosbag_completion_ws/results/long_optimized_retry_20261031_5fdb722e26c541149cdf7cd2eed45fc2/report.md`。bag 时间戳跨度约 277.17 秒；节点接收 55,435 条 IMU、2772 帧点云，2768 帧常规处理。外部订阅者收到里程计、Path、注册点云及节点 TF 各 2768 条。点云内部队列退出时为 0。播放器自然结束；节点在等待 30 秒后由脚本主动 SIGINT 停止。播放期间节点 CPU 采样均值 17.31%（100% 为一逻辑核）、RSS 采样峰值 370.45 MiB。

尾段内部处理耗时和外部延迟上升，RSS 也随时间增长。现有证据不足以归因于优化、Path 发布、订阅观察者或内存泄漏。没有优化前长包对照，不可声称长包已有性能收益。

本候选版额外修改运行日志路径；上述数字来自此前隔离副本实验，并非本候选版重新测得。
