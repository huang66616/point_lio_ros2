- 播放器 `natural_end`，读取、入队、出队、publish API 均为 **3967**，退出码 0。publish API 计数本身不证明 DDS 送达。
- 节点完成 IMU 初始化，控制台有 **176** 条常规帧处理计时记录，独立运行目录中的位置日志有 **176** 行。

- 节点的三个日志文件均写入其独立 `pointlio-XXXXXX` 目录。运行前后原仓库 `Log/pos_log.txt`、`Log/mat_out.txt`、`Log/imu_pbp.txt` 的 SHA-256 均相同。
- 节点控制台未见 ERROR；有初始化与人为中断相关 WARN。本次没有新增节点输入回调计数器，因此不能独立证明 3607 条 IMU 和 180 帧点云逐条送达；历史诊断实验有该项证据。
